# Decisões — Hub Volta Express Brasil

Registro curto de decisões (formato ADR). Cada uma diz o contexto, o que foi decidido, a alternativa descartada e o custo aceito.

| # | Data | Decisão | Alternativa descartada | Custo aceito |
|---|---|---|---|---|
| D1 | 27/10/2026 | **O Hub é público e só mostra conteúdo publicável ou agregado.** Pastas internas ficam fora do catálogo (`PRIVADO` em `scripts/comum.py`) e o validador falha se alguma aparecer. | Hub privado com login (Cloudflare Access) | Números internos (receita, CAC, OKRs) não entram até existir uma área privada |
| D2 | 27/10/2026 | **Pesquisa publicada só em agregado anônimo.** Grupos com menos de 3 respostas viram "Outros"; formulários com menos de 10 respostas ficam de fora; local só por UF; nome, e-mail, telefone, horário e texto livre são ignorados. | Publicar as planilhas ou citar respostas | Perde-se detalhe (cidade, comentários) |
| D3 | 27/10/2026 | **Vídeos ficam como arquivo local com capa e `preload="none"`.** O campo `youtube` da curadoria já existe: preenchido, o Hub passa a usar o player do YouTube. | Subir já para o YouTube | Repositório continua com ~55 MB de vídeo até a migração |
| D4 | 27/10/2026 | **Gráficos feitos à mão, sem biblioteca.** Barras em HTML/CSS (texto legível no celular); colunas empilhadas em SVG. Todo gráfico tem a tabela de dados ao lado ("Ver dados em tabela"). | Chart.js / ECharts | Tipos de gráfico limitados aos dois que o Hub usa |
| D5 | 27/10/2026 | **Design system herdado da landing v7.** `shared/tokens.css` é cópia do arquivo da landing (cores, fonte, espaçamentos, contraste já medido). | Pacote compartilhado entre os repositórios | Mudança de token precisa ser copiada nos dois repositórios |
| D6 | 27/10/2026 | **Trabalho na branch `features/dashboard-inteligente-v1`.** | Direto na `main` | Merge manual depois da revisão |
| D7 | 27/10/2026 | **Dados gerados por script e validados por JSON Schema (draft-07).** Nada de número escrito à mão no JavaScript. | Catálogo mantido à mão em `js/data.js` (v6, 96 KB) | É preciso rodar `python scripts/gerar_tudo.py` depois de mexer nas pastas |
| D8 | 27/10/2026 | **Rotas por `#` (`#/pesquisa`, `#/relatorios/<id>`).** Funciona no GitHub Pages sem configuração e cada seção tem link próprio. | Rotas com caminho real (`/pesquisa`) | URLs com `#` |
| D9 | 27/10/2026 | **Versões leves em `midia/` (WebP 480 e 1600 px, capas de vídeo 720 px); originais mantidos em `assets/` para download.** | Substituir os originais | Repositório guarda os dois (+~17 MB) |
| D10 | 27/10/2026 | **Sem visualizador de PDF, XLSX e DOCX.** Esses formatos eram todos internos (B0); o código abre como texto simples. Saem Tailwind CDN, Prism, SheetJS e Mammoth. | Manter os visualizadores | Para ver um PDF futuro, o Hub oferece o download |
| D11 | 27/10/2026 | **Relatórios publicados a partir dos `.md` de cada projeto** (`scripts/gerar_relatorios.py`). `DEMONSTRACAO.md` e `AMBIENTE-LOCAL.md` da plataforma ficam de fora porque têm credenciais de teste; HTML bruto (`script`, `iframe`, `style`) é escapado. | Copiar o texto à mão para o Hub | O Hub só atualiza quando o script roda |
| D12 | 27/10/2026 | **A capa de vídeo usa o quadro de 3 s.** Em 20 s o vídeo do mapa mostra um número de telefone sendo discado, que não deve virar imagem de capa. | Quadro escolhido automaticamente | Ver o achado A3 no relatório |
| D13 | 27/10/2026 | **Vídeo do mapa oculto do Hub.** A revisão quadro a quadro mostrou que é gravação de tela real: nome de pessoa, telefones e notificações de WhatsApp de terceiros. | Manter público até alguém editar | Demonstrações fica com 2 vídeos até a regravação com dados de teste |
| D14 | 27/10/2026 | **Pasta `inspiracoes/` (30 imagens) oculta do Hub.** São layouts, fotos e componentes de outras marcas usados como referência. Publicados num Hub da empresa, sugerem autoria, trazem risco de direito autoral e não comprovam nada sobre a Volta Express. | Manter como "Referências de mercado" | O processo de pesquisa visual deixa de aparecer; pode voltar como texto ("o que aprendemos com X") sem as imagens |
| D15 | 27/10/2026 | **Infográfico de tamanhos de caminhão (terceiro) oculto.** Os números continuam na seção Explicações, com a fonte descrita e o aviso de que não foram validados com a operação. | Publicar a imagem | Nenhum: o dado útil já está em texto e gráfico |
| D16 | 27/10/2026 | **Filtros do Acervo só mostram opções que existem, com contagem.** | Lista fixa de rótulos | — |
| D17 | 27/10/2026 | **`scripts/servir.py` em vez de `python -m http.server`** para testar localmente. No Windows o Python pode servir `.js` como texto e os módulos não carregam. | Instruir a mexer no registro do Windows | Um arquivo a mais em `scripts/` |
| D18 | 27/10/2026 | **Remoção de arquivos continua manual (com você).** Tudo o que sai foi listado em `docs/remover-apos-v7.txt`; ocultar pela curadoria é reversível em 1 linha, apagar não. | Apagar direto | O repositório só emagrece quando você executar a lista |
